# Aplicación de Notas - Proyecto de React

## 1. Requisitos / Introducción

Este proyecto consiste en una aplicación web para crear, editar, eliminar, y visualizar notas. La aplicación permite gestionar notas de manera simple y eficiente. A lo largo del desarrollo, se integran las siguientes funcionalidades:

- **Fase 1**: Creación de notas, edición, eliminación y visualización.
- **Fase 2** (opcional): Aplicación de etiquetas a las notas y filtrado por categorías.

### Consideraciones importantes:
- La **fase 1** es obligatoria para completar este ejercicio.
- La **fase 2** es opcional, pero proporciona puntos extras.
- La persistencia de datos se realiza en una base de datos relacional mediante un ORM.
